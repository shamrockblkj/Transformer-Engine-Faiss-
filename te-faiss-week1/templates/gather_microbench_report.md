# gather 吞吐微基准报告（模板）

- 对应协议：[../eval_protocol.md](../eval_protocol.md)
- 对应任务：V2.8 Gate 1 实验①正式查表微基准；开发计划 W2
- 正式源码：[`../w2_gather/lut_gather_bench.cu`](../w2_gather/lut_gather_bench.cu)。本程序是查表微基准，**不是**完整解码内核；收件或未触发停机线都**不批准**开始内核开发。
- 填写说明：只填**官方 RTX 4090 24GB**上的实测。改装 48G 或非 24GB 卡的结果不得作为 V2.8 正式验收。禁止把 H100 口径的 1.2 ms/token 写成官方停线，禁止把 V2.8 第 4.2 节估算（含 0.5 ms、2.3 ms、每 token 查找次数）抄成实测，禁止编造基线数字。
- 本周范围：按正式程序对比 `codes_only`、`lut_l2`、`lut_smem<8>`（64 KB）、`lut_smem<4>`（32 KB）。网格须与 V2.8 第 4.1 节一致（`block=256`；默认 8 组/块，32 KB 对照为 4 组/块）。**不做**融合 Epilogue、残差小核或 CUDA Graph，也不写全量 CUDA 解码内核（内核开发须等阶段 3 批准）。
- 编译须用冻结的 CUDA 12.8，架构 `sm_89`。上机前须通过已写入 `lut_gather_bench.cu`（2026-11-26 22:10）的硬检查：sm_89，且显存 24000–25000 MiB（按 `totalGlobalMem / 1024²`，不要用十进制 GB）；检查未通过不得开跑。
